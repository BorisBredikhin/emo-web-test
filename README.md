Локальный запуск с помощью python:

```bash
./start.sh
```

либо поместить в корень любого web-сервера.

## Структура проекта

```
- index.html           # точка входа: подключает style.css и js-скрипты
- start.sh             # запуск локального HTTP-сервера
- style.css            # стили приложения
- questions.json       # список заданий (id + label)
- imgs/                # изображения
  - 1.png ... 5.png  # картинки заданий (имя файла = id)
  - *.svg          # иконки
- js/
  ─ helpers.js       # утилиты: $, $$, shuffle(), validateKey(), markText()
  ─ consts.js        # константы: QUESTIONS, VOWELS
  ─ menu.js          # класс Menu — навигация по заданиям
  ─ cross.js         # класс CrossButton — кнопка перезапуска
  ─ game.js          # класс Game — основная логика + точка входа
```

В `imgs/` помещаются файлы изображений, в `questions.json` - список заданий в формате:

```
[
  {
    "id": 1,
    "label": "зелень"
  },
  ...
]
```

`id` - имя файла изображения без расширения, строка или число.

## Описание архитектуры

Приложение написано на ванильном JavaScript в парадигме ООП. Скрипты подключаются в [`index.html`](index.html:11) в порядке, гарантирующем доступность утилит и классов: `helpers` → `consts` → `menu` → `cross` → `game`.

### Классы

- Game - основная логика;
- Menu - панель навигации;
- CrossButton - кнопка «крестик», по клику перезапускает игру.
